# IINA字幕打字插件 \- 产品需求计划书（最终版）

## 一、项目概述

开发一款**IINA 播放器 JS 插件**，实现：加载视频字幕 → 逐行字幕打字练习 → 实时对错判断 → 打完自动播放下一句 → 支持盲打模式。

使用场景：用户观看外语/台词/歌词视频，一边看字幕，一边手动打字跟读，提升输入速度、正确率、记忆力。

核心特性：**完全窗口内输入、无需全局键盘、纯插件实现、不依赖任何外部软件**

## 二、核心定位（明确边界）

- ✅ **只做窗口内打字**（焦点在插件输入框才生效，正常网页输入逻辑）

- ✅ **只对接 IINA 插件体系**，不做独立客户端、不做MIDI、不做音频、不做全局按键

- ✅ **纯字幕打字训练**，对标“打字游戏、字幕跟读、逐句练习”

## 三、整体运行流程（主逻辑）

1\. IINA 打开视频，自动加载当前视频对应的 SRT 字幕

2\. 插件解析字幕，得到：每一行文本、开始时间、结束时间

3\. 视频自动暂停，进入「单句打字练习模式」

4\. 界面展示：当前需要输入的目标字幕 \+ 用户实时输入内容（红绿对错）

5\. 用户完整正确输入当前句子 → 视频自动播放本句时长

6\. 本句播放结束 → 自动暂停，切换下一句，循环往复

## 四、详细功能需求（MVP 完整版）

### 1\. 字幕解析模块

- 兼容**外挂SRT字幕 \+ 视频内嵌多语言软字幕**两种场景，支持自由切换使用

- 可读取IINA当前激活播放的字幕轨道，解析结构：`index、startTime、endTime、text、语种`

- 自动过滤空行、无效字幕、时间轴异常行、重复字幕行

- 识别视频内嵌多字幕轨道（中英日韩等），同步读取所有可用字幕语种列表

- 跟随IINA播放器字幕切换操作，插件实时同步当前生效字幕数据源

### 2\. 打字练习核心功能（最核心）

- 弹出独立 Webview 输入窗口（带原生 HTML input 输入框）

- 实时逐字符比对：
       

    - 输入正确 = 绿色

    - 输入错误 = 红色

    - 未输入 = 灰色占位

- 支持退格删除、连续修正

- 支持空格、标点、大小写完全匹配（可配置是否忽略大小写）

### 3\. 视频自动联动逻辑

- 进入单句练习 → 自动暂停视频

- **整行完全输入正确后 → 自动播放视频**

- 播放到当前字幕结束时间 → 自动暂停，切换下一句

- 支持手动：跳过本行、重置本行、上一句/下一句切换

### 4\. 盲打模式（重点特色）

- 开关控制：显示字幕 / 隐藏字幕（盲打）

- 盲打模式下：用户看不到原句，只能自己听视频、凭记忆打字

- 打完自动比对，展示对错结果

### 5\. 画面 UI 叠加（IINA Overlay）

- 视频顶部悬浮显示当前练习句 UI

- 实时展示：正确率、当前行数、总句子数

- 配色规则：正确绿、错误红、待输入灰

### 6\. 数据统计

- 单句正确率

- 错字数量、修正次数

- 整体练习进度百分比

### 7\. 基础设置项

- 忽略大小写 开关

- 忽略首尾空格 开关

- 盲打模式快速切换按钮

- 重置当前句子

- 字幕语种切换：读取视频内嵌所有字幕轨道，支持插件内手动切换语种，适配多语言打字练习

- 字幕源自适应：自动优先跟随IINA当前激活字幕（内嵌软字幕/外挂字幕自动适配）

## 五、交互逻辑（用户视角）

1. 打开视频 \+ 加载字幕

2. 点击插件「开始打字练习」

3. 弹出输入小窗口，视频自动暂停在当前句子

4. 用户逐字输入，实时变色提示对错

5. 完全输入正确 → 视频自动播放本句

6. 播放完毕自动暂停，进入下一句

7. 全程循环练习，直到视频结束

## 六、非功能需求（明确不做）

- 不做全局键盘监听

- 不做后台挂机识别打字

- 不做独立客户端，只做 IINA 插件

- 不识别视频**硬字幕（画面内嵌无法关闭的字幕）**，仅支持标准软字幕轨道

## 七、技术架构（最简稳定版）

**1\. 插件主脚本 main\.js**

- 字幕解析、状态管理、对错比对、视频播放控制

- 管理句子索引、播放状态、统计数据

**2\. Standalone 独立 Webview 窗口**

- 原生 input 输入框，解决所有打字捕获问题

- 通过 postMessage 和主脚本双向通信

**3\. Video Overlay 悬浮层**

- 展示字幕彩色校对 UI、进度、提示文字
